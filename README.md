# 美柚省钱移动端预览项目

## 预览入口

直接打开根目录下的 `index.html` 即可预览项目。

导出到手机时，请将整个项目文件夹一起导出，保持以下目录结构不变：

```text
index.html
avatar.png
*.svg
src/
  data/
  scripts/
  styles/
backup/
```

## 手机预览

1. 将整个项目文件夹传到手机，或通过局域网文件服务访问。
2. 使用手机浏览器打开 `index.html`。
3. 页面支持首页、搜索优惠、我的页面、设置页和底部导航交互。

项目不需要安装 Node.js、npm 或其他依赖，也没有构建步骤。

## 资源说明

- `src/styles/`：页面样式和设计主题。
- `src/scripts/app.js`：页面切换和交互逻辑。
- `src/data/`：首页、生活服务和商城示例数据。
- 根目录 SVG：平台和业务图标。
- `avatar.png`：我的页面头像资源。
- `backup/`：历史版本备份，不参与当前页面运行。
- 商品示例图使用 Unsplash 外链，手机预览时需要网络；无网络时对应位置会显示空白或占位背景。

## 当前入口

首页搜索区域可以进入“搜优惠”页面，页面左上角返回按钮可以回到首页。底部导航可以切换首页、天天补贴、柚子街和我的页面。
